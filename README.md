# Мой Ритм

**Мой Ритм** — одностраничный wellness-сайт в стиле AI-first digital product: питание, активность, напоминания и персональные рекомендации в тёмном premium-интерфейсе.

## О проекте

Сайт объединяет ощущение заботы о здоровье и современный digital-дизайн: неоновые акценты, glassmorphism, плавные анимации и ощущение «живого» AI-помощника.

**Главные возможности:**
- рецепты и подбор питания;
- учёт калорий и активности (шаги);
- напоминания и режим **Календарь**;
- настройка **Мои параметры** под пользователя;
- пробный доступ **10 дней бесплатно**.

## Структура папки

```
Мой Ритм/
├── moi-ritm.html      # главная страница (HTML + CSS + JS)
├── assets/
│   └── hero-wellness.mp4   # видео на главном экране
└── README.md
```

## Технологии

- HTML5, CSS3, JavaScript (vanilla)
- Tailwind CSS (CDN)
- Шрифты: Space Grotesk, Inter
- SVG-анимация кардиолинии (ECG)
- Видео в hero-блоке

## Как открыть

1. Откройте файл `moi-ritm.html` в браузере (Chrome, Edge, Firefox).
2. Убедитесь, что рядом есть папка `assets` с файлом `hero-wellness.mp4` — иначе видео на главном экране не загрузится.

## Дизайн

- тёмная luxury-тема (`#03040b`);
- акценты: cyan `#5ee9ff`, violet `#8b6dff`, pink `#ff7ab8`;
- неоновая кардиолиния под заголовком;
- голографические и neural-эффекты на фоне.
